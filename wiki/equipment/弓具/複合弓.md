# 複合弓（Compound Bow）

> 複合弓是射箭界最年輕的競技弓種，以滑輪與纜線系統提升機械效率，使箭速與精準度達到所有弓種中最高水準。

---

## 概述

複合弓於 **1960 年代**發明，設計目標是製造比傳統弓更具機械效率的射箭器材。其核心特色是**滑輪（Cam）與纜線（Cable）**系統，讓弓在拉開後握持重量大幅降低，能量傳遞效率也優於反曲弓。世界射箭聯合會於 **1990 年代**正式承認複合弓，並自 **1995 年**起納入世界射箭錦標賽項目。

複合弓目前與[[wiki/equipment/弓具/反曲弓]]並列為現代競技射箭的兩大主流弓種，參與 Hyundai 世界盃射箭賽（自 2006 年起）及世界運動會。

---

## 射擊方式

複合弓射手使用**放箭輔助器（Release Aid）**鉤住弦上的 D 形環（D-loop），向後拉弓至機械止點（Hard Stop）。拉弓過程中所需力量會**先增後減**，在滿弓時的握持重量（Holding Weight）可低至 **6 公斤（約 13 磅）**，讓射手能更穩定地瞄準。

射手透過**放大瞄準鏡（Magnified Scope）**瞄準靶心，扣動放箭輔助器脫離弦，彎曲弓臂與纜線中儲存的能量將箭射出。複合弓箭速可超過 **350 kph**，遠高於反曲弓。

## 器材構成

### 主要部件

| 部件 | 英文 | 說明 |
|------|------|------|
| **弓把** | Riser | 以碳纖維或鋁合金製成，結構需承受極大張力 |
| **弓臂** | Limbs | 較短，高剛性 |
| **滑輪（凸輪）** | Cam | 核心機構，控制拉力曲線與放繩特性 |
| **纜線** | Cable | 連接兩端滑輪，傳遞能量 |
| **D 形環** | D-loop | 固定在弓弦上，放箭輔助器的接觸點 |
| **瞄準鏡** | Scope | 附放大功能，提升精準度 |
| **穩定桿** | Stabiliser | 比反曲弓更多樣的配置 |
| **箭座** | Arrow Rest | 通常使用落式箭座（Drop-away Rest）以減少羽翼干擾 |
| **纜線護桿** | Cable Guard | 防止纜線干擾箭矢飛行 |
| **放箭輔助器** | Release Aid | 手持或手腕式，取代手指放箭 |

---

## 與反曲弓的主要差異

| 項目 | 反曲弓 | 複合弓 |
|------|--------|--------|
| 瞄具 | 無放大功能 | 附放大鏡 |
| 放箭方式 | 手指 | 機械放箭輔助器 |
| 滿弓握持重量 | 等於拉力 | 大幅降低（約 60-80% 減重） |
| 箭速 | >200 kph | >350 kph |
| 奧運項目 | ✅ | ❌（非奧運） |
| 世錦賽項目 | ✅ | ✅（1995 年起） |
| 箭矢震盪方向 | 水平 | 垂直 |

## 技術規格摘要

| 項目 | 數值／說明 |
|------|-----------|
| 最大拉力 | 約 28 公斤（60 磅） |
| 滿弓握持重量 | 最低約 6 公斤（13 磅） |
| 箭速 | 超過 350 kph |
| 材質 | 碳纖維、鋁合金 |
| 規格要求 | 器材需承受長期高張力，有嚴格測試規範 |
